The first public release of **Scout**, a fast, keyboard-friendly file browser for macOS.

### Install
1. Download **Scout.zip** below and open it.
2. Drag **Scout** into **Applications**.
3. Open it. The first time, macOS says it can't verify the app: click **Done**, go to **System Settings ▸ Privacy & Security**, and click **Open Anyway** next to Scout. You only do this once.
4. When macOS asks whether Scout can see your Downloads, Desktop and Documents folders, click **Allow**.

Needs macOS 26 or later. Works on Apple silicon and Intel Macs.

### Highlights
- **⌥Space from any app** opens a palette that jumps to any folder or finds any file in a few keystrokes.
- **Tabs and split view** that come back after you quit.
- **Move To… (⇧⌘M):** send files anywhere by typing a few letters, no dragging.
- **Open folders in Scout:** make Scout the app folders open in, from Spotlight, downloads and other apps.
- **Clean Up:** old installers, big downloads, duplicates and developer caches, all to the Trash with undo.
- **Tidy Folder, Rename Items, workspaces, tags, Shelf, Quick Actions**, and nearly every Finder feature.
- **Fast with huge folders:** 10,000 files open in about a third of a second.
- **For developers:** Git status, Open in Terminal/editor, Homebrew and npm packages, `scout://` links, a `scout` command and a Raycast extension.
